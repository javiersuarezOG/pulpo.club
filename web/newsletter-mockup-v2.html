v2.2 changes from v2.1: personal voice removed entirely (no "I", "my", "Sebas" signature, no fabricated agent calls). Pulpo speaks in third person throughout. The BUY / WATCH / SKIP verdicts are gone — replaced with data-derived signal pills (TOP MATCH, BELOW ZONE, PRICE DROP, BUILD READY, NEW, DATA FLAG) that map to actual fields in Listing (rank_score, price_vs_zone_pct, is_repriced, readiness_score, days_listed). Comp tape replaced with "Pulpo benchmark" using the real price_vs_zone_median + zone_comp_count fields. All listings are real (pulled from ranked.json).
BLOCK 1 — Cover rewritten. No "we found", no "Sebas", no fabricated stories. Pulpo speaks in third person. The lede explains what Pulpo did (scanned 1,247 listings) and how it ranked them (composite score). The summary list cites real data signals — every number is computable from ranked.json.
BLOCK 2 — "My read" → "Pulpo signal". Same data, third-person phrasing. No personal opinion ("If you're waiting…"). Just describes what the data shows and what it implies — leaves the decision to the reader.
BLOCK 3 — "The take" → "What the data shows". Four data-grounded bullet points, each pointing to a real Pulpo field (rank_score, price_vs_zone_pct, days_listed, readiness_score). No fabricated stories, no "I walked it last Tuesday", no agent quotes. The signal pills replace the BUY/WATCH/SKIP verdict — they map directly to data fields. The "Pulpo benchmark" replaces the fake Sold/Active/Pulled comp tape with what Pulpo actually computes: price_vs_zone_median, zone_comp_count, time-on-market range.
BLOCK 4 — Verdict column gone, signal pills replace it. Every pill maps to a data field: rank_score percentile, price_vs_zone_pct, is_repriced, readiness_score, days_listed. Signal legend at the bottom is the contract — readers can audit any pill against the listing detail page.
BLOCK 5 — Price-drop feature. Replaces the old "WATCH" pick. Every claim is verifiable against is_repriced + previous_price. The save CTA is reframed: "Save to track price drops" — because saving a listing already triggers Pulpo's drop alerts on the site.
BLOCK 6 — "Don't bother" → "Pulpo flagged these for data issues". No fabrications. Every flag is something Pulpo can actually detect: duplicate listings across sources (Pulpo already does dedup), missing utility data (readiness_score = 0), stale with no price drop (days_listed + !is_repriced). Phrasing is descriptive ("Pulpo flagged", "Pulpo can't distinguish") — never opinionated ("skip this", "walk away").
BLOCK 7 — "Tired sellers" rephrased honestly. Old version had "I would offer 22-28% below" — that's editorial. Pulpo doesn't recommend offers; it just shows the days_listed + price-history signals and lets the buyer decide. The framing is "the data suggests" not "you should".
BLOCK 8 — "Your Pulpo" loop unchanged. Already system-integrated. Numbers come from real per-recipient state (saves count, filter summary, filter-match count).
