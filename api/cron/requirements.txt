# datetime, http.server, os, time, traceback). Without this file,
# Vercel's Python runtime falls back to the root `requirements.txt`

# the function bundle past Vercel's 500MB Lambda ephemeral-storage
# limit. Co-locating this empty requirements.txt shadows the root one
# so no deps get installed for this function.
